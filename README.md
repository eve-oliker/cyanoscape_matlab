# cyanoscape_matlab
Scripts written for the processing of CyanoSCape in-situ data for submisison to NASA's SeaBASS repository. 
Adapted from the glakes project https://zenodo.org/records/21683614.

For in-depth information on utilizing scripts, visit the project wiki or https://docs.google.com/document/d/1_3koZInglCrY-6xyRqLDOWjNX8oAExrtmC8XpCKLm3w/edit?usp=sharing.
